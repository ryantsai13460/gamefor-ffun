# Media sources

The YouTube section preserves the 24 original Unstable SMP and Minecraft creator videos and includes a larger static catalog of gaming Shorts and standard YouTube videos in `assets/media-curated.js`. The curated library requires no API key. Titles and creators were verified through YouTube's oEmbed metadata. Gaming Shorts link to their YouTube Shorts pages. Thumbnails load from YouTube's own CDN, with title placeholders when the browser cannot fetch an image.

## Movies

The cinema catalog has 134 complete films, including 21 features and 113 shorts. A separate collection preserves 12 studio trailers. The catalog uses the official YouTube and NFB players for supported entries and opens the archive or provider for direct viewing. Film detail pages link to the source and credits. [Blender Studio Films](https://studio.blender.org/films/) · [Pixar Films](https://www.pixar.com/feature-films) · [DreamWorks Movies](https://www.dreamworks.com/movies)

The November 21, 2026 expansion adds 84 National Film Board of Canada films. The NFB's title, director, year and runtime metadata were checked against each film page. Each new official embed returned a full-film player, and the matching publisher poster or still returned an image. Four earlier NFB entries have a regional availability notice. Provider access can change with location, licensing or browser settings. [NFB Collection](https://collection.nfb.ca/) · [NFB Animation](https://www.nfb.ca/animation/) · [NFB Documentaries](https://www.nfb.ca/documentary/)

The expansion also adds eight silent prints cataloged as U.S. public domain by Wikimedia Commons and six films made available through the Library of Congress National Screening Room. The archive viewing pages and matching film stills were checked. The arcade links to those players and the archive's rights information. Runtimes reflect the specific prints offered. [Wikimedia Commons licensing policy](https://commons.wikimedia.org/wiki/Commons:Licensing) · [The General](https://commons.wikimedia.org/wiki/File:The_General_(1926).webm) · [National Screening Room](https://www.loc.gov/collections/national-screening-room/about-this-collection/) · [National Film Registry viewing links](https://www.loc.gov/programs/national-film-preservation-board/film-registry/watch-films-on-the-national-film-registry/)

## Music library

The chart lyrics catalog contains 550 distinct songs from the Billboard Hot 100 and Apple Music national Top Songs charts dated November 21, 2026. Each row displays the rank on its source chart. Matched songs open creator lyric videos, and other songs link to a title-and-artist video search. Apple Music may require sign-in or a subscription to show song lyrics. [Billboard Hot 100](https://ca.billboard.com/charts/hot-100/2026-11-21) · [Apple Music chart feeds](https://rss.marketingtools.apple.com/)

The arcade supplies text-only artwork and uses YouTube’s embedded player. Video footage and lyrics are served by YouTube. ## Creator library and search service

Creator imports use the official YouTube Data API and a site-restricted key entered by the user. The importer keeps public video metadata and finished creator catalogs in browser storage. It uses the key in memory during the request and clears the key field before the import begins. Import and export are also available as a local JSON file.

The optional connected search setting supports the previous endpoint format. On a search, it issues a GET with `q`, `safeSearch=strict`, and `videoEmbeddable=true`. The endpoint must return JSON in the form `{"items":[{"id":"a YouTube video ID","title":"Video title","creator":"Channel name"}]}`. Cross-origin endpoints need to permit browser requests from the deployed site. The static build includes local search and a link to search on YouTube. The connected search service and its credentials run separately.
